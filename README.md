# Varvara Karenski's Project Portfolio
Here, you're able to see documentation of my research work, projects, and experience. 

This project was made with 99% HTML and CSS. 
Also a teensy bit of Javascript for interactive navigation.

## Live at: 
[varvarakarenski.github.io/project-portfolio](https://varvarakarenski.github.io/project-portfolio/)

## Features: 
- Pretty cutting-mat background for featured work
- Blueprint-style background for projects
- Collapsible menu
- Cute buttons for skills
- Manila folder design for experience
- Animations on hover
- Notepad and animated eraser in featured section

### Sections:
- Featured: my most recent work or the work I'm most proud of
- Projects: Hardware & Software projects
- GitHub Gallery: Links to my projects that can be found on GitHub
- Experience: details my career experience in frontend design, ML research, and education
- Skills: Languages and tools I'm familiar with
